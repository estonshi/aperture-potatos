# potatOS v0.4.0（spec 0.4）

## 新增

- **MCP server 名称保留大小写**：名称允许 `^[A-Za-z0-9_-]{1,64}$`，工具名沿用宿主配置里的写法；prompt 命令仍把 server 部分转小写。
- **conformance 覆盖补齐**：新增扩展 hook 点用例（`skill_activate`、`mcp_elicitation`、`peer_auth_required`、`subagent_start`）、`command.output`、`provider.raw`、模型列表、`session_end`、`post_tool_batch` 与 `tool.abandoned`。runner 新增 `agent.raw_events`、`providers[].models` 和命令 `outputs`，并允许扩展测试传入自带的 hook 点。

## 行为变更

1. 同步 hook 通过 session 引起的事件（如 `registry.changed`）现在保证在该 hook 的 `hook.completed` 之前发布；之前两者来自不同 goroutine，顺序不定。规范 §10.2 已固定该顺序。

## 迁移

- spec 从 0.3 对齐到 0.4；SDK `v0.4.0` 满足 spec 0.4，`v0.4.y` 都满足 spec 0.4，全部 conformance 用例已迁移。
- 依赖 hook 事件与其内部注册事件“顺序不定”的订阅方需要按新顺序调整。
- 名称含 `__` 的 MCP server 会让 `mcp__<server>__*` 规则覆盖到另一个 server 的工具，宿主需避免。

## 验证

- `go build ./...`、`go vet ./...`、`gofmt -l` 无输出。
- `go test ./...` 全绿；新增用例多次复跑稳定。
- live：`deepseek-flash` 下 skills、mcp、kernel 等通过；Anthropic tool search、显式缓存与 OpenAI hosted web search 因端点不支持而未通过。
