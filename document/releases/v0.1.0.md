# potatOS v0.1.0（spec 0.1）

首个发布：语言无关的规范、Go 实现与一致性用例。规范编号 `0.1`，SDK 版本 `v0.1.0`。

## 规范

`runtime.md` 是每个绑定的规范正文，覆盖：

- I1–I10 不变量；事件顺序 O1–O5 与投递保证 G1–G6。
- 消息与会话文件：RULE-STORE-001 到 RULE-STORE-011，每个 session 一个 append-only JSONL，epoch 与写批，可选的 calls 文件与 label 记录，以及恢复。
- session 与 turn：阶段、turn 循环与结局、attempt 与重试、gate 之后的工具组与中断、调用账本（一次 HTTP 请求算一次调用）、hosted tools 与工具搜索、session labels。
- 输入队列、命令（`run_now`、`wait_idle`、`interrupt`、`reject`）、系统提示词骨架、固定文本、模型与能力、17 个 hook 点、审批、上下文管理（压缩、pin、clear、rewind、fork、side chat、history search）、任务与派生 agent。

配套内容：

- 9 个 schema：`common`、`message`、`event`（57 个内核 payload）、`provider`、`hook`（17 个点）、`tool`、`command`、`task`、`approval_rule`，每个都有正例与反例。
- 数据文件：`errors.json`（三类 API 的错误分类）、`stop_reasons.json`、`limits.json`、`runtime_tags.json`。
- 提示词：`system.core.md`、`identity.md`、`user.md`、`agent_message.md`、`task_started.md`、`task_notification.md`，以及 `reminders.md` 的 44 条固定文本。
- 映射：`projection.md`、`anthropic_messages.md`、`openai_chat.md`、`openai_responses.md`。

## 扩展

`ext/README.md` 规定共享规则：文本沿用 `runtime.md` §7 的模板语言，事件与 hook 点各有 schema。

- `compact`、`history`、`mcp`、`memory`、`peer`、`skills`、`subagent`、`tasks`。
- 七个命令扩展：`cmd.clear`、`cmd.compact`、`cmd.context`、`cmd.fork`、`cmd.help`、`cmd.rewind`、`cmd.usage`。

## 一致性

- 第一层 provider：解码 `anthropic.messages` 27 例、`openai.chat` 26 例、`openai.responses` 26 例（其中 4 例录自真实端点）；渲染 34/20/22 例；错误分类 18/21/16 例。
- `prompt/`：mustache 23 例（14 个模板、9 个畸形模板），系统骨架 5 例。
- `store/`：17 例，其中 8 例读会话文件、9 例恢复。
- 第二层：`loop/` 136 个内核用例，`loop/ext/` 64 个扩展用例；每个用例同时断言 I1、I2、I4、I6、I9、I10。
- `a2a/`：`v03/httpjson` 11、`v03/jsonrpc` 12、`v10/httpjson` 12、`v10/jsonrpc` 10 个客户端用例，以及 14 个发现用例。
- `conformance/runner-protocol.md` 规定 runner 写出 `actual.*`、`actual.skip` 或 `actual.fail`，`conform diff` 与 `conform update` 按 `conformance/README.md` 的规则比对或接受。
