# potatOS 开发指南

potatOS 是一个用 Go 编写的 agent core SDK，用于在你自己的程序中构建能够调用工具、多轮工作的 agent，第 1 章对它有完整的介绍。本指南面向使用 potatOS 的开发者，介绍如何接入、如何配置、如何扩展，以及使用时需要遵守的约束。指南只讲接口的用法，不涉及内部实现。如果你想先了解运行机制，请阅读上一级目录中的 [architecture.html](../architecture.html)。

> 说明：本指南对应的 module 为 `github.com/estonshi/aperture-potatos`，要求 Go 1.25，内容与 spec 0.4 版本保持一致。

## 阅读方式

如果你是第一次接入，建议按顺序阅读第 1、2、3 章，先跑通快速开始中的例子，再根据需要跳到后面的章节。如果你的 agent 已经运行起来，可以直接在下文的“按需求查找章节”中找到对应内容。

每一章开头都有一段说明，介绍这一章解决什么问题、什么时候需要阅读。除常见问题一章外，正文之前都列有本章目录。多数章节末尾有“建议做法”一节，汇总了实践中总结出的推荐写法。

## 约定

- 代码示例中的 `kernel`、`provider`、`event`、`message`、`store` 都是本 module 下的包，它们的 import 路径见 [1.5](01-overview.md#15-常用的包)。
- 术语 turn、step、epoch 直接使用英文，定义见 [3.2](03-core-objects.md#32-术语)。
- 表格中的“默认”指你不做设置时的取值。对于注明“负数不限”的字段，设置为负数表示取消这个上限。
